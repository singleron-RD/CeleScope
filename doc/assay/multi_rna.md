## Usage

### 1. Create a genome directory

#### Homo sapiens

```bash
mkdir hs_ensembl_110
cd hs_ensembl_110

wget https://ftp.ensembl.org/pub/release-110/fasta/homo_sapiens/dna/Homo_sapiens.GRCh38.dna.primary_assembly.fa.gz
wget https://ftp.ensembl.org/pub/release-110/gtf/homo_sapiens/Homo_sapiens.GRCh38.110.gtf.gz

gunzip Homo_sapiens.GRCh38.dna.primary_assembly.fa.gz
gunzip Homo_sapiens.GRCh38.110.gtf.gz

conda activate celescope

celescope utils mkgtf \
  Homo_sapiens.GRCh38.110.gtf \
  Homo_sapiens.GRCh38.110.filtered.gtf

celescope rna mkref \
  --genome_name Homo_sapiens_ensembl_110_filtered \
  --fasta Homo_sapiens.GRCh38.dna.primary_assembly.fa \
  --gtf Homo_sapiens.GRCh38.110.filtered.gtf \
  --mt_gene_list mt_gene_list.txt
```

#### Mus musculus

```bash
mkdir mmu_ensembl_110
cd mmu_ensembl_110

wget https://ftp.ensembl.org/pub/release-110/fasta/mus_musculus/dna/Mus_musculus.GRCm39.dna.primary_assembly.fa.gz
wget https://ftp.ensembl.org/pub/release-110/gtf/mus_musculus/Mus_musculus.GRCm39.110.gtf.gz

gunzip Mus_musculus.GRCm39.dna.primary_assembly.fa.gz
gunzip Mus_musculus.GRCm39.110.gtf.gz

conda activate celescope

celescope utils mkgtf \
  Mus_musculus.GRCm39.110.gtf \
  Mus_musculus.GRCm39.110.filtered.gtf

celescope rna mkref \
  --genome_name Mus_musculus_ensembl_110_filtered \
  --fasta Mus_musculus.GRCm39.dna.primary_assembly.fa \
  --gtf Mus_musculus.GRCm39.110.filtered.gtf \
  --mt_gene_list mt_gene_list.txt
```

`--mt_gene_list` specifies the path to a plain-text file containing mitochondrial genes for the reference genome, with one gene symbol per line. During the `celescope utils mkgtf` step, a default `mt_gene_list.txt` file is automatically generated by identifying all gene symbols that begin with the prefix `"MT-"` or `"mt-"`.

For more details about the `mkgtf` command, please refer to [mkgtf.md](../mkgtf.md).

For mixed-genome analysis, typically a human–mouse mixture, please refer to [human_mouse](https://github.com/singleron-RD/human_mouse).

### 2. Generate scripts for each sample

In your working directory, create a shell script named `run.sh`:

```bash
multi_rna \
  --mapfile ./rna.mapfile \
  --genomeDir {path to hs_ensembl_110 or mmu_ensembl_110} \
  --thread 16 \
  --soloCellFilter EmptyDrops_CR \
  --mod shell
```

#### Arguments

`--mapfile`
Required. The mapfile is a tab-delimited text file containing at least three columns. Each line represents one pair of FASTQ files.

* 1st column: FASTQ file prefix
* 2nd column: FASTQ file directory
* 3rd column: Sample name, which will be used as the prefix for all output files

Example:

Sample 1 has two paired-end FASTQ files located in two different directories, `fastq_dir1` and `fastq_dir2`. Sample 2 has one paired-end FASTQ file located in `fastq_dir1`.

```bash
$ cat ./my.mapfile
fastq_prefix1	fastq_dir1	sample1
fastq_prefix2	fastq_dir2	sample1
fastq_prefix3	fastq_dir1	sample2

$ ls fastq_dir1
fastq_prefix1_1.fq.gz	fastq_prefix1_2.fq.gz
fastq_prefix3_1.fq.gz	fastq_prefix3_2.fq.gz

$ ls fastq_dir2
fastq_prefix2_1.fq.gz	fastq_prefix2_2.fq.gz
```

`--genomeDir`
Required. The path to the genome directory generated by `celescope rna mkref`.

`--thread`
The recommended number of threads is 16. Using more than 20 threads is generally not recommended, because [the mapping speed of STAR tends to saturate above approximately 20 threads](https://github.com/singleron-RD/CeleScope/issues/197).

`--mod`
Specifies the script type to generate. Available options include `sjm`, which uses [Simple Job Manager](https://github.com/StanfordBioinformatics/SJM), and `shell`, which generates standard shell scripts.

After running:

```bash
sh run.sh
```

a `shell` directory containing `{sample}.sh` files will be generated.

Start the analysis by running:

```bash
bash ./shell/{sample}.sh
```

Please note that `./shell/{sample}.sh` must be executed from the working directory. It should not be run from inside the `shell` directory.

## Main output

* `outs/{sample}_Aligned.sortedByCoord.out.bam`
  Coordinate-sorted BAM file containing reads aligned to the genome.

* `outs/raw`
  Gene expression matrix containing all barcodes from the barcode whitelist, including both background and cell-associated barcodes.

* `outs/filtered`
  Gene expression matrix containing only cell-associated barcodes.

## Seurat `CreateSeuratObject`

When using Seurat’s [`CreateSeuratObject`](https://www.rdocumentation.org/packages/Seurat/versions/3.0.1/topics/CreateSeuratObject), the default value of `names.delim` is an underscore (`_`). Since cell barcodes are also separated by underscores, for example `ATCGATCGA_ATCGATCGA_ATCGATCGA`, using the default `names.delim = "_"` may incorrectly set `orig.ident` to one segment of the barcode.

This issue can be avoided by setting `names.delim` to another character, such as `"-"`:

```r
seurat.object = CreateSeuratObject(
  matrix,
  names.delim = "-",
  project = "sample_name"
)
```

## Additional matrix filtering

After completing the `multi_rna` workflow, you can run `celescope rna cells` on the existing results to perform cell calling again. This step supports forced cell number filtering, minimum gene number filtering, and maximum mitochondrial gene fraction filtering. It will generate a new expression matrix and HTML report. The original expression matrix and HTML report will be renamed with the prefix `default_`.

### Example 1: Adjust cell-calling parameters

For more details about STARsolo EmptyDrops-like filtering, please refer to:
[https://github.com/alexdobin/STAR/blob/master/docs/STARsolo.md#emptydrop-like-filtering](https://github.com/alexdobin/STAR/blob/master/docs/STARsolo.md#emptydrop-like-filtering)

```bash
# In CeleScope v1.*, the default FDR for cell calling is 0.01.
# In CeleScope v2.*, the default FDR is 0.001.
# The following parameters set the FDR to 0.01:

celescope rna cells \
  --soloCellFilter "EmptyDrops_CR 3000 0.99 10 45000 90000 500 0.01 20000 0.01 10000" \
  --outdir test1/cells \
  --sample test1
```

### Example 2: Force cell number and apply QC filters

The following command forces the cell number to 10,000, then retains cells with at least 200 detected genes and a mitochondrial gene fraction no greater than 0.05.

```bash
celescope rna cells \
  --force_cells 10000 \
  --min_gene 200 \
  --max_mito 0.05 \
  --genomeDir /genome/rna/celescope2/mmu \
  --outdir test1/cells \
  --sample test1
```
