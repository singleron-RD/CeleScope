## Usage

### 1. Create a genome directory

For genome reference generation, please refer to [rna](multi_rna.md) assay.

---

### 2. Generate scripts for each sample

In your working directory, create a shell script named `run.sh`:

```bash
multi_dynaseq \
  --mapfile ./dynaseq.mapfile \
  --genomeDir {path to genome directory} \
  --thread 16 \
  --mod shell
```

For control sample, set `--control` to skip the replacement step:

```bash
multi_dynaseq \
  --mapfile ./dynaseq.mapfile \
  --genomeDir {path to genome directory} \
  --thread 16 \
  --mod shell \
  --control
```

#### Arguments

`--mapfile`
Required. The mapfile is a tab-delimited text file containing at least three columns. Each line represents one pair of FASTQ files.

* 1st column: FASTQ file prefix
* 2nd column: FASTQ file directory
* 3rd column: Sample name, which will be used as the prefix for all output files
* 4th column: Optional, forced cell number
* 5th column: Optional, background SNP file

Example:

Sample 1 has two paired-end FASTQ files located in two different directories, `fastq_dir1` and `fastq_dir2`. Sample 2 has one paired-end FASTQ file located in `fastq_dir1`.

```bash
$ cat ./dynaseq.mapfile
fastq_prefix1	fastq_dir1	sample1
fastq_prefix2	fastq_dir2	sample1
fastq_prefix3	fastq_dir1	sample2

$ ls fastq_dir1
fastq_prefix1_1.fq.gz	fastq_prefix1_2.fq.gz
fastq_prefix3_1.fq.gz	fastq_prefix3_2.fq.gz

$ ls fastq_dir2
fastq_prefix2_1.fq.gz	fastq_prefix2_2.fq.gz
```

`--genomeDir`
Required. The path to the genome directory generated by `celescope rna mkref`.

`--thread`
The recommended number of threads is 16.

`--mod`
Specifies the script type to generate. Available options include `sjm`, which uses [Simple Job Manager](https://github.com/StanfordBioinformatics/SJM), and `shell`, which generates standard shell scripts.

After running:

```bash
sh run.sh
```

a `shell` directory containing `{sample}.sh` files will be generated.

Start the analysis by running:

```bash
bash ./shell/{sample}.sh
```

Please note that `./shell/{sample}.sh` must be executed from the working directory. It should not be run from inside the `shell` directory.

## Dynaseq-specific Arguments

### conversion step

`--basequalilty`
Min base quality of the read sequence. Default: `20`

`--snp_min_depth`
Minimum depth to call a SNP. Default: `20`

`--snp_threshold`
SNP threshold filter. Greater than `snp_threshold` will be recognized as SNP. Default: `0.5`

`--readsplit`
Split to have approximately N reads per output file. Default: `1000000`

`--conversionMem`
Set conversion memory (G). Default: `5`

### substitution step

`--all_type_plot`
Plot substitution rate for all conversion types.

### replacement step

`--control`
For control samples to generate background SNP files and skip replacement.

`--replacementMem`
Set replacement memory (G). Default: `50`

## Main output

### Gene expression matrix

* `outs/{sample}_Aligned.sortedByCoord.out.bam`
  Coordinate-sorted BAM file containing reads aligned to the genome.

* `outs/raw`
  Gene expression matrix containing all barcodes from the barcode whitelist, including both background and cell-associated barcodes.

* `outs/filtered`
  Gene expression matrix containing only cell-associated barcodes.

* `outs/labeled`
  Labeled gene expression matrix.

* `outs/unlabeled`
  Unlabeled gene expression matrix.

* `outs/{sample}.h5ad`
  H5AD file containing `['total', 'labeled', 'unlabeled']` layers and TOR rate of each cell/gene.

### Conversion outputs

* `conversion/{sample}.PosTag.bam`
  BAM file with conversion info.

* `conversion/{sample}.PosTag.csv`
  TC conversion sites info in CSV format.

* `conversion/{sample}.snp.csv`
  Candidate SNP sites.

### Substitution outputs

* `substitution/{sample}.TC_substitution.txt`
  Substitution rate of labeled and background sites.

* `substitution/{sample}.substitution.txt`
  Tab-separated table of the overall conversion rates.

### Replacement outputs

* `replacement/{sample}_labeled_detail.csv`
  Comma-delimited file:
    * `Barcode`: Cell barcode sequence
    * `UMI`: UMI sequence
    * `geneID`: Gene ID
    * `TC`: TC site number in a read (background SNP removed)
