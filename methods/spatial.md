#### Read Processing and Quantification

Paired-end FASTQ files were analyzed using CeleScope v2.15.4 ([https://github.com/singleron-RD/CeleScope](https://github.com/singleron-RD/CeleScope)). Reads were aligned to the Ensembl GRCh38 (human, release 110) or GRCm39 (mouse, release 110) reference genome using STAR (v2.7.11a) in STARsolo mode. Reference indices were built using `celescope rna mkref` based on unfiltered GTF annotations, retaining short non-coding RNAs. Spot barcode segments were matched against predefined whitelists, allowing up to two mismatches per barcode (`--soloCBmatchWLtype EditDist_2`). UMIs were then collapsed to remove PCR duplicates. Cell calling was disabled by setting `--soloCellFilter None`. Downstream analyses utilized expression matrices generated by the `GeneFull_Ex50pAS` counting strategy.

#### In-Tissue Spot Selection

Spot coordinates, in-tissue flags, and pixel positions were derived from registered H&E images using AtlasXbrowser ([https://github.com/singleron-RD/AtlasXbrowser](https://github.com/singleron-RD/AtlasXbrowser)). Only spots with `in_tissue = 1` were retained for further analysis. 

#### Downstream Analysis

Expression matrices were converted into Visium-compatible HDF5 files and a Space Ranger–style spatial directory, enabling seamless loading into Scanpy. Analysis was performed using Scanpy v1.9.3 (AnnData v0.7.6). Genes expressed in fewer than 3 spots and spots expressing no detected genes were removed.For dimensionality reduction and clustering, raw counts were normalized using analytic Pearson residuals directly without prior library-size scaling, followed by the selection of 2,000 highly variable genes (HVGs). Principal Component Analysis (PCA) was computed (50 components), and a 15-nearest-neighbor graph constructed on the top 25 principal components was embedded via UMAP. Spots were grouped into clusters using the Leiden algorithm at a resolution of 0.3.For marker gene identification, raw counts were separately normalized to total counts per spot (10,000 counts/spot) and log1p-transformed. Differentially expressed genes per cluster were identified using Wilcoxon rank-sum tests with Benjamini–Hochberg correction for multiple testing (adjusted $P < 0.05$).
